01

Hackathon · Oct 2026 1st place

A crypto wallet where the key never exists in one place

Swissquote track, Blockchain Association Hackathon

Built with a team of three. The private key is split with 2-of-3 threshold-ECDSA (DKLs23), so Swissquote co-signs and screens payments but can never move funds on its own. Face ID passkeys (WebAuthn PRF) unlock the client’s share.

  • Gasless USDC/EURC transfers (EIP-3009)
  • Time-locked recovery with key refresh
  • dApp policy with dry runs on Ethereum Sepolia, 15 end-to-end API tests

TypeScript · React · Node.js · MPC

02

GPU kernels · Feb – May 2026

Making GPT-2 fast, one CUDA kernel at a time

A tiled FlashAttention-2 kernel written in CUDA C++ from the paper, for GPT-2 124M inference. It removes the O(N²) round-trips to GPU memory while keeping the output logits correct.

19.3×
faster attention
16×
faster decoding with a KV cache
24.5% → 1.7%
attention’s share of GPU time

Also removed shared-memory bank conflicts with XOR swizzling (2.6× per GEMM), and used CuTe-tiled GEMMs with SM80 tensor-core instructions for 1.41× end-to-end throughput.

CUDA C++ · CUTLASS / CuTe · Nsight Compute

03

Internship · Moffatt & Nichol · from May 2026

Simulating a port before it’s finished being built

Simulation Software Engineering Intern, Costa Mesa, CA

A reusable C++/Lua framework inside the FlexTerm simulation software, for a port under construction in Australia. A dispatcher drives interacting finite-state machines that schedule pilots, tugs and berths as vessels move through weather, tunnel and resource limits.

Profiling tools feed Power BI dashboards on berth occupancy, wait times and tug use, so engineers can test staffing in simulation instead of in the field. That saves an estimated hundreds of thousands of dollars in field tests.

C++ · Lua · FlexTerm · Power BI

04

Research · EPFL · Fall 2026 in progress

What happens to Mixture-of-Experts inference when routing gets lopsided

A benchmark for expert-parallel MoE inference on two H100 GPUs (60 experts, top-4 routing), timing how long each GPU spends dispatching, computing and combining at every step.

early numbers: skewed routing made steps 25–48% slower. Full write-up coming soon.

PyTorch · CUDA · Nsight Systems

Also: a Unix systems suite in C, with a non-blocking epoll file server and a Minix-style filesystem (Feb – May 2026).
